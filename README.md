# Customer_Churn_Prediction_Project
Built an end-to-end churn prediction project for a telecom company, engineering 28 features on 100,000 customers and selecting XGBoost (0.70 ROC-AUC) via 5-fold cross-validation. Translated predictions into business value with a profit and break-even model and a 90-day A/B test design. Tech: Python, Pandas, scikit-learn, XGBoost.
